# Апроксимація функцій (ГА)

Вебдодаток для апроксимації поліноміальних функцій за допомогою **генетичного алгоритму**.
Варіант 25 — Параметрична ідентифікація.

---

## Реалізований функціонал

| Функція | Опис |
|---|---|
| **Генетичний алгоритм** | Пошук коефіцієнтів полінома P(x) = a₀ + a₁x + … + aₙxⁿ |
| **Мінімізація MSE** | Середньоквадратична похибка як цільова функція |
| **Метрика R²** | Коефіцієнт детермінації для оцінки якості апроксимації |
| **Турнірний відбір** | Стохастичний відбір батьківських особин |
| **BLX-α схрещування** | Арифметичне злиття батьківських хромосом |
| **Гаусівська мутація** | Адаптивна σ (лінійний спад по поколіннях) |
| **Елітизм** | Збереження найкращих N особин без змін |
| **Рання зупинка** | Автоматична зупинка при відсутності покращення |
| **Два графіки** | Апроксимація + збіжність алгоритму (live-оновлення) |
| **Завантаження даних** | Ручне введення або завантаження CSV/TXT файлу |
| **Журнал подій** | Запис усіх дій і помилок із можливістю збереження у `app.log` |
| **Експорт результатів** | Збереження звіту у `results.txt` |
| **Конфігурація** | Усі параметри за замовчуванням у `config.json` |
| **Валідація вводу** | Зрозумілі повідомлення про помилки, перевірка діапазонів |

## Як запустити

> **Важливо:** додаток використовує ES-модулі (`import`/`export`),
> тому потрібен локальний HTTP-сервер (не відкривати як `file://`).

### Варіант 1 — Python (рекомендовано)
```bash
cd pr1
python -m http.server 8080
# Відкрийте: http://localhost:8080
```

### Варіант 2 — Node.js (npx)
```bash
cd pr1
npx serve .
```

### Варіант 3 — VS Code Live Server
Встановіть розширення **Live Server**, правий клік на `index.html` → *Open with Live Server*.

## Параметри алгоритму (`config.json`)

| Параметр | За замовч. | Опис |
|---|---|---|
| `polynomialDegree` | 3 | Степінь полінома |
| `populationSize` | 100 | Кількість хромосом |
| `generations` | 300 | Максимум поколінь |
| `mutationRate` | 0.1 | Ймовірність мутації гена |
| `crossoverRate` | 0.8 | Ймовірність схрещування |
| `eliteCount` | 5 | Елітних особин |
| `coefRangeMin/Max` | −10/10 | Початковий діапазон коефіцієнтів |
| `patience` | 60 | Поколінь без покращення → зупинка |

## Алгоритм

```
Ініціалізація популяції: коефіцієнти ~ U[coefMin, coefMax]
Для кожного покоління:
  1. Обчислити MSE і f = 1/(1+MSE) для кожної хромосоми
  2. Елітизм: перенести топ-N у нову популяцію
  3. Поки нова популяція < popSize:
     a. Турнірний відбір двох батьків
     b. BLX-α схрещування
     c. Гаусівська мутація (σ зменшується з часом)
  4. Рання зупинка: якщо patience поколінь без покращення
Повернути найкращу хромосому + метрики
```
